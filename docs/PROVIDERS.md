# Voice provider evaluation for V0

**Checked 2026-10-15 against official provider documentation.** This compares documented interfaces and published prices, not actual bills, perceived latency, voice quality or household suitability. Separate
[synthetic evidence](testing/LIVE_VOICE.md) now confirms OpenAI account access and
one bounded WebRTC response, with no microphone or household data. No account, billing profile or legal agreement was created or accepted during this work.

| Option | Current V0 state | Interface and published audio price | Data handling relevant to Wanda |
| --- | --- | --- | --- |
| OpenAI `gpt-realtime-2.1` | Synthetic WebRTC response/audio and server hangup verified; microphone and voice quality unverified | The [WebRTC guide](https://developers.openai.com/api/docs/guides/voice-webrtc) documents a server-side API key and browser SDP exchange through `/v1/realtime/calls`. The [model page](https://developers.openai.com/api/docs/models/gpt-realtime-2.1) lists $32 input and $64 output per million audio tokens; its free tier is unsupported. | [OpenAI data controls](https://developers.openai.com/api/docs/guides/your-data) say API data is not used for model training unless opted in. For `/v1/realtime`, the table lists default abuse monitoring retention of 30 days, no application-state retention, and eligibility for Zero Data Retention. Enhanced retention controls require separate approval and are **not** configured for Wanda. |
| Google Gemini Live | Alternative only; no Wanda adapter | The [Live API reference](https://ai.google.dev/api/live) documents preview, stateful WebSocket sessions for streamed audio, text and function calls. The [pricing page](https://ai.google.dev/gemini-api/docs/pricing) lists `gemini-2.5-flash-native-audio-preview-12-2025` at $3 input and $12 output per million audio tokens on its paid tier; the listed free tier has no token charge. These are an example model's published rates, not an estimate of a Wanda session. | The [pricing page](https://ai.google.dev/gemini-api/docs/pricing) labels free-tier data as used to improve products and paid-tier data as not used for that purpose. [Gemini terms](https://ai.google.dev/gemini-api/terms) say unpaid content may be human reviewed, while paid services may still log prompts/responses for abuse monitoring. [Google's retention guide](https://ai.google.dev/gemini-api/docs/zdr) says Live session resumption can retain conversation state, including audio, for up to 24 hours. The [terms' use restrictions](https://ai.google.dev/gemini-api/terms) require review before any consumer household deployment. |
| Fully local voice | Not implemented | No model, transport, supported hardware profile, quality benchmark or operating cost has been selected. | A correctly local pipeline could avoid sending live audio to a cloud provider, but its actual privacy and usability would depend on the chosen components and tests. The text demo and mock home controls remain available without cloud voice. |

These published per-token rates do not establish monthly cost: session length, audio tokenization, conversation history, caching, output volume and provider billing rules matter. Recheck current documentation and measure a synthetic session before judging Wanda's $60–$100/month planning target. [Gemini Live best practices](https://ai.google.dev/gemini-api/docs/live-api/best-practices) specifically warn that retained session context can be billed again across turns.

Wanda's default demo makes no provider call. The optional OpenAI path sends microphone audio only after configuration and a per-session disclosure/consent step. **Inference from the streaming architecture:** consent or local memory rules cannot remove a name, address or other personal detail after someone has already spoken it into an active cloud session. Use synthetic speech for development. Before real household use, the owner must review provider processing, retention and terms; decide whether to enable a paid API account; confirm any account-specific data controls; set a spending limit; and test live access, interruptions, language switching and cost. A Gemini alternative would require separate terms, data-use and regional eligibility review. No provider is accepted as the permanent V1 choice; the adapter boundary permits replacement.
